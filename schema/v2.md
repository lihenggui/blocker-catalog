# Blocker catalog format 2

A catalog consists of a manifest, SDK rules, Android component descriptions,
and icons. The uncompressed catalog is under `out/v2/`. The transport files
are under `out/release/`.

JSON uses UTF-8 without a byte order mark. Unicode characters are written
directly except where JSON syntax requires escaping. JSON documents and
JSON Lines records end with a line feed. Omit absent optional fields.
`null` is invalid. An explicit empty text string is a defined value.

## `catalog.json`

The manifest is a JSON object indented by two spaces. All fields are required.

| Field | Type | Meaning |
| --- | --- | --- |
| `format` | Integer | Must equal `2`. |
| `sequence` | Non-negative integer | Catalog sequence supplied by `--sequence`. Defaults to `0`. |
| `sourceCommit` | String | Source commit supplied by `--source-commit`. Defaults to an empty string. |
| `publishedAt` | String | ISO instant ending in `Z`, supplied by `--published-at`. Defaults to `1970-01-01T00:00:00Z`. |
| `files` | Array of objects | One entry for every catalog file other than `catalog.json`, sorted by `path`. |

Each entry contains the following required fields.

| Field | Type | Meaning |
| --- | --- | --- |
| `path` | String | Unique relative path within the catalog, using forward slashes. |
| `sha256` | String | SHA-256 digest of the uncompressed file bytes as 64 lowercase hexadecimal digits. |
| `size` | Non-negative integer | Number of bytes in the uncompressed file. |

## `rules.json`

This file is a JSON object with one required field, `rules`, an array of
rule objects sorted by ascending `id`.
The JSON is indented by two spaces.

| Field | Type | Presence | Meaning |
| --- | --- | --- | --- |
| `id` | Positive integer | Required | Unique stable app rule ID. |
| `icon` | String | Optional | Relative path to an existing file under `icon/`. An empty source `iconUrl` denotes absence. |
| `website` | String | Optional | Rule website from the legacy renderer. |
| `keywords` | Array of strings | Required | Legacy `searchKeyword` values in their rendered order after upstream merge, normalization, and exclusions. The array may be empty. |
| `safeToBlock` | Boolean | Optional | The rule's safety recommendation. |
| `contributors` | Array of strings | Required | Legacy contributor values in their rendered order. The array may be empty. |
| `i18n` | Object | Required | Language objects keyed by `en` and optionally `zh-CN`. |

A language object can contain `name` (rule display name), `company`
(company display name), `description` (rule description), and `sideEffect`
(effect of blocking). All four fields are strings. Only `en.name` is
required and must be nonempty. For English `name` and `description`, local
text takes precedence over linked Exodus text. Each Chinese field comes from
its Chinese source. Clients match keywords as case-insensitive literal
substrings of component names. The schema has no regex or network-signature
fields.

## `components.jsonl`

Each line contains one compact JSON object, with no spaces after commas or
colons. Objects are sorted by `name`, which is unique. An empty catalog of
components has an empty file. The keys occur in the following order, with
absent optional keys omitted.

| Field | Type | Presence | Meaning |
| --- | --- | --- | --- |
| `name` | String | Required | Fully qualified Android component class name derived from its source path. |
| `sdkRuleId` | Positive integer | Optional | ID of an existing rule selected by the longest case-insensitive literal keyword match against `name`. The lowest rule ID wins ties. Omitted when no keyword matches. |
| `recommendToBlock` | Boolean | Required | Whether the source recommends blocking the component. |
| `contributor` | String | Optional | Contributor credited by the source. |
| `updatedAt` | String | Optional | Source `lastUpdateTime` ISO instant, preserving the original string. |
| `i18n` | Object | Required | Language objects keyed by `en` and optionally `zh-CN`. |

A language object can contain `description` (component description) and
`disableEffect` (effect of disabling the component). Both fields are strings.
Only `en.description` is required.

## Localization

Each language object contains the text fields defined for that language.
An optional language object is omitted when it has no defined fields.
For each field, the client uses the requested language's value if the field
is present. Otherwise it uses the English value if present. If both values
are absent, the field remains absent. An empty string stops fallback.

## Icons and transport files

Transport assets use `v<format>-<file>`, with a `.gz` suffix for the two
data files and `v<format>-icons.zip` for icons. The format prefix lets
multiple catalog formats share a release. Format 2 clients fetch
`…/latest/download/v2-catalog.json` on GitHub. When format 2 is retired,
the asset is absent from the latest release and clients can prompt users
to update Blocker.

The `icon/` tree contains copies of the files in `data/icons/`.
Paths and bytes are preserved. File paths and component names are sorted in
case-sensitive Unicode code point order.

| File in `out/release/` | Contents |
| --- | --- |
| `v2-catalog.json` | Byte copy of `out/v2/catalog.json`. |
| `v2-rules.json.gz` | Gzip of `rules.json` at compression level 9, with modification time zero and no original filename in the header. |
| `v2-components.jsonl.gz` | Gzip of `components.jsonl` with the same settings. |
| `v2-icons.zip` | Deflated icon files sorted by their `icon/<file>` paths. Every entry has timestamp `1980-01-01 00:00:00`, regular-file permissions `0644`, and no extra fields. |

Use manifest hashes and sizes to verify the decompressed payload files and
the extracted icons.
